The targets are YAML declarations, npm registry advisories, external state such as GitHub's default branch parse and repository settings, and command acceptance. Copying these into fixed-value Vitest tests cannot verify the real registry, workflow, Dependabot job or REST response, so no automated test file is added. Instead, each Case ID is tracked through YAML parsing, the scoped diff, the exit code and main output of exact commands, read-only API responses and the evidence of post-merge operations. Because no test code is added, Given / When / Then comments, mock assertions and coverage measurement do not apply.
