Perspectives for the orchestration that takes the `for-each-ref` snapshot first, runs `rev-list --left-right --count` only on the snapshot's validated commit OIDs through `evalPromises()` with `BRANCH_COMPARISON_MAX_PARALLEL = 3`, fetches worktrees, the remote name list and refs/remotes independently, and isolates failures per fact (implementation plan §3.2 / §4 Task 2). NUL parsing, the fallback decision rules and the row-building branches are the responsibility of `src/branchCleanup-test.md` S1 to S4; this table only covers Git arguments, call counts, failure isolation and the degree of parallelism.
