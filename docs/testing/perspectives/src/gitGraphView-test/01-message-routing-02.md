## S24: viewDiff() resolves HEAD with resolveRefToHash and adds a version query for uncommitted changes

> Origin: フェーズ2 修正 M9/M10 (view-diff-resolve-head)
> Added: 2026-07-04T02:44:58Z
> Status: active
> Supersedes: S16
> Signature: `private async viewDiff(repo, commitHash, oldFilePath, newFilePath, type, compareWithHash?): Promise<boolean>`
> Target Path: `src/gitGraphView.ts:745-800`

A fix that replaces the mutable `HEAD` reference in uncommitted diffs with `dataSource.resolveRefToHash(repo, "HEAD")` (a fixed hash resolved by rev-parse), falling back to `"HEAD"` when it cannot be resolved. The resolved hash builds `actualFromHash` in compare mode (`compareWithHash !== undefined`) and the left URI in the non-compare uncommitted mode (`compareWithHash === undefined` and `commitHash === UNCOMMITTED_CHANGES_HASH`). The right URI on the uncommitted side (type `D`) gets a version query via `encodeDiffDocUri(..., Date.now().toString())` to invalidate the cache. The `try/catch` around the three `vscode.diff` calls (returning `false` on an exception) carries over the perspectives of the old S16. This section replaces the old S16 (which assumed `HEAD` was embedded directly).
