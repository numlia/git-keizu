## S48: Worktree label rendering (branch lookup on the collection and a display-only detached label)

> Origin: Feature 052 (detached-worktree-display) (light-spec-plan)
> Added: 2026-08-08
> Updated: 2026-08-08
> Status: superseded
> Superseded By: S55
> Supersedes: S35
> Signature: `private renderTable(): void` / `loadCommits(commits, commitHead, moreAvailable, forceRender, authors?, worktrees?: GG.WorktreeCollection)`
> Target Path: `web/main.ts` (branch label rendering, detached label rendering, and the contextmenu / dblclick / click handlers of `gitRef`; update to a line range after implementation)
> Test File: `tests/web/main.test.ts`

A change that switches the webview's internal state and the worktree argument of `loadCommits()` to `WorktreeCollection`, moves the branch label lookup to `worktrees.branches`, and renders the display-only label `gitRef worktree detachedWorktree` for each worktree whose `DetachedWorktreeInfo.head` matches the commit row's hash and whose `isMain === false`. The detached label has no `data-name`, does not open the branch context menu on right-click, and does not check out on double-click. S35 fixed the branch label display contract on the assumption that the lookup source was the flat `worktreeMap`, so it is superseded, and its branch-side expected results are carried over into this section. The diff helper itself belongs to `web/utils-test.md` S5, and building the response data belongs to `src/dataSource-test/02-branch-worktree-03.md` S47.
